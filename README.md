# Emorce Byte

Your Discord. Powered by Emorce.

Selfbot hoster dashboard + worker — black hexed, pin accents, crimson CTAs.

## Quick start

```bash
# worker (real 24/7 hosting)
cd worker && npm i && npm i discord.js-selfbot-v13 && node index.js

# dashboard
npm i && npm run dev
```

Live dashboard: deploy this repo root to Vercel (Next.js).
Worker should run on Railway/VPS for token hosting.

Selfbots violate Discord ToS — own accounts only.
